# IT Devices and Software Tracker: Relational Database & Data Visualization

## Project Overview

This project focuses on designing a structured system for tracking IT devices, software, and inventory-related information using a relational database and data visualization approach. The goal is to improve visibility into IT assets, reduce manual tracking issues, and support better reporting for IT operations.

This project connects my **Information Technology** background with my **Business Analytics** experience by showing how database design, reporting, and visualization can support real IT support and asset management workflows.

## Problem Statement

IT teams often need to track devices, software, users, and asset-related details across multiple systems or spreadsheets. Without a structured tracking process, it becomes harder to understand device ownership, software usage, inventory status, and operational needs.

This project explores how a relational database and reporting workflow can help organize IT inventory data more clearly and support better decision-making.

## Project Goals

- Design an organized tracking system for IT devices and software
- Use relational database concepts to structure asset-related information
- Improve visibility into IT inventory and software records
- Support reporting and analysis through organized data
- Demonstrate how database design can improve IT operations and asset management
- Connect technical IT workflows with business analytics and data visualization

## IT Support Relevance

This project is relevant to IT support and service desk work because asset visibility is an important part of supporting users and maintaining operations. A structured tracker can help answer questions such as:

- Which devices are assigned to which users?
- What software is installed or being tracked?
- Which assets may need updates, replacement, or review?
- How can IT inventory data be organized for faster reporting?
- How can structured data reduce manual tracking errors?

## Business Analytics Relevance

From a business analytics perspective, this project demonstrates how organized data can support better operational decisions. Instead of relying only on manual notes or disconnected spreadsheets, a relational model can make it easier to analyze inventory, identify trends, and create reports for stakeholders.
